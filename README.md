# Homebrew tap for Osprey

Osprey is the Ubiquiti PTZ controller for an existing Frigate installation.

```sh
brew install grayslawson/osprey/osprey
```

Or tap it first:

```sh
brew tap grayslawson/osprey
brew install osprey
```

The formula is kept in step with the Osprey repository by a scheduled
workflow, which points it at the latest published release. The source of
truth is the [Osprey repository](https://github.com/grayslawson/osprey).
